# PROTOCOLO DE HANDOFF · v2.0 — quem entrega o quê
Setup → todos: config, Planilha v2, base_custos, baseline. Analista → Diretor/Otimizador/especialistas: leitura hierárquica maturada. Diretor → Comitê: diagnóstico. Rentabilidade → Arquiteto/Otimizador/Escalador/Publicador: CPA máx bruto, tROAS/tCPA convertidos, veto. Tracking → todos: estado do sinal, lag, veto de escala. Merchant → Shopping/PMax/Product: aprovações, feed, custom labels gravados. Product → Shopping/PMax/Escalador: ranking HERO/CORE/…/labels. Keywords-Terms → Search/Publicador: negativas e novas keywords com risco avaliado. Search/PMax/Shopping/Brand/Demand-Video → Otimizador: achados por canal. Assets → Search/PMax/Demand: criativos com hipótese. Testes → Otimizador/Assets: fechamentos. Otimizador → Publicador: ações completas (fato→…→reset→review). Escalador → Publicador/Budget: plano com checklist. Budget → Comitê/Publicador: alocação bruta. BI-Alertas → dono/Orquestrador: placar + alertas. Radar → Comitê/todos: mudanças de plataforma + skill atualizada. Auditoria → Publicador/Comitê: veto/liberação. Publicador → execution_log + solicitante: evidência.
Regras: handoff sem FATO/NATUREZA volta · para o Publicador só chega com vetos consultados · quem recebe confirma em 1 linha · ninguém chama todos.
